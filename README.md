# GENR8-3D Website

Production-style React + Tailwind website for GENR8-3D with a futuristic maker-lab UI.

## Stack

- React 19 + TypeScript
- React Router for multi-page IA
- Tailwind CSS
- Vite

## Pages

- `/` Home
- `/services` Services
- `/services/:slug` Service Detail
- `/products` Product Gallery (clocks, plaques, pins, keyrings, school furniture)
- `/digital-solutions` Digital Solutions (marketing page linking to https://solutions.genr83d.com/)
- `/portfolio` Portfolio
- `/about` About
- `/contact` Contact + Quote Request

## Local Setup

1. Install dependencies:
   - `npm install`
2. Start dev server:
   - `npm run dev`
3. Build production output:
   - `npm run build`
